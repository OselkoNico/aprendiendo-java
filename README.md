# Aprendiendo Java ☕

Mi plan de 24 semanas para pasar de JavaScript/TypeScript a **Java + Spring Boot**, con el objetivo de construir una aplicación full stack (Spring Boot + Angular) desplegada.

Vengo de desarrollar con TypeScript, Angular, React y Node.js, así que a lo largo del plan comparo cada concepto de Java con su equivalente en TS.

## 🗺️ Plan

| Mes | Tema | Semanas |
|-----|------|---------|
| 1 | Fundamentos: sintaxis, arrays, POO, herencia, interfaces y excepciones | 1-4 |
| 2 | Java moderno: genéricos, lambdas, Streams, Maven y tests con JUnit 5 | 5-8 |
| 3-4 | Spring Boot: API REST, PostgreSQL con Spring Data JPA, validación y tests | 9-16 |
| 5-6 | Nivel profesional: Spring Security + JWT, Swagger, Docker, despliegue y proyecto final con Angular | 17-24 |

## 📁 Estructura

Cada semana tiene su propia carpeta con los ejercicios y mini-proyectos:

```
aprendiendo-java/
├── semana-01/   Sintaxis y entorno
├── semana-02/   Arrays y listas
├── semana-03/   Programación orientada a objetos
└── ...
```

## 🛠️ Tecnologías

- Java 21 (Eclipse Temurin)
- IntelliJ IDEA
- Maven y JUnit 5 (a partir de la semana 7)
- Spring Boot y PostgreSQL (a partir de la semana 9)

## ▶️ Cómo ejecutar los ejercicios

1. Clona el repositorio.
2. Abre la carpeta de la semana en IntelliJ IDEA (con JDK 21).
3. Ejecuta la clase que quieras con el botón ▶️ junto al método `main`.
